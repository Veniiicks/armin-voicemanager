# Армин — голосовой ИИ-ассистент и операционная система arminOS

![Армин](icon.png)

**«Армин»** — умный голосовой ИИ-ассистент, который живёт в вашем компьютере:
слушает, отвечает, печатает за вас, управляет системой, интернетом, музыкой и
презентациями. Проект включает две версии приложения и собственную
операционную систему на его основе.

| Ветка | Платформа | Статус |
|---|---|---|
| **Windows** | Windows 10/11 | ✔ Стабильная, готовый инсталлятор |
| **Linux** | Ubuntu/Debian 22.04 | 🔧 **Техническая остановка разработки** |
| **arminOS** | Собственный live-дистрибутив | 🔧 **В разработке** |

---

## Возможности

- 🗣️ **Голосовое управление** — пробуждение по имени («Армин!»),
  распознавание речи, диктовка текста в активное окно.
- 🤖 **ИИ-общение** — чат с ИИ: OpenRouter, Groq, Google Gemini, Hugging Face
  и локальный Ollama (авто-fallback). Автономный агент «сделай …»
  планирует и выполняет цепочку действий.
- 🎵 **Музыка** — локальные треки, радиостанции, Spotify (OAuth PKCE).
- 🌐 **Фирменный браузер** в стиле «Армина» (тёмная тема, свой профиль).
- 🖥️ **Управление системой** — выключение/перезагрузка, сон, Wi-Fi,
  громкость и яркость, пакеты apt, службы systemd, пользователи.
- 📋 **Задачи, заметки и приложения** — по голосу или в чате.
- 🧮 **Математика** — быстрый парсер в C++-ядре.
- 📽️ **Презентации (Windows)** — управление PowerPoint вслух.

## Состав проекта

### Windows

Готовая программа для Windows: `Armin_Home_Setup.exe` (инсталлятор Inno
Setup). Распознавание Google Speech Recognition, ИИ через OpenRouter, режим
печатания под диктовку, управление PowerPoint и медиа, свои команды.

### Linux

Python (Tkinter GUI) + **C++ ядро** (`libarmin_core.so` через ctypes).
Локальное распознавание **Vosk** (оффлайн, ~50 МБ модель), четыре ИИ-
провайдера и Ollama, музыка (файлы/радио/Spotify), диспетчер задач как в
Windows 11, браузер «Армин», встроенные приложения. 

### arminOS (в разработке)

**arminOS** — собственная операционная система на базе **Ubuntu 22.04 LTS**,
в которой «Армин» встроен из коробки: загрузился — и он уже слушает.

- Live-ISO (XFCE, LightDM) с фирменным брендингом: GRUB, plymouth, обои
  (см. `armin-ubuntu/branding/preview/`).
- **Кастомный GTK-установщик** вместо ubiquity: анализ железа (RAM/GPU/CPU →
  выбор DE), установка окружения (GNOME/XFCE/LXQt), каталог ПО, разбивка
  диска, выбор и загрузка Ollama-модели.
- Автозапуск установщика в live-сессии; Армин ставится на целевой диск.

Статус: ISO собирается, установщик в работе; цель — стабильный релиз
arminOS 1.0 с полным брендингом (GRUB/GDM/Plymouth).

## Безопасность

- Пароль sudo в Linux не хранится в коде/файлах; передаётся командой
  «пароль …» в чате и хранится только в `settings.json` с правами `0600`.
- Пароль маскируется в чате и логах.
- API-ключи ИИ держите только в настройках приложения — **не кладите ключи
  в код и текстовые файлы** (и не коммитьте их).
- Системные команды (выключение, установка пакетов и др.) требуют
  подтверждения.
